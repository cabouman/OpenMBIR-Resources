svmbir on conda-forge

conda-forge is svmbir's main channel. Each column is one released version and the number of times its conda-forge package has been downloaded. Downloads of a version keep accumulating after the next one is released, so the newest version is still growing.

Of these downloads, 163,964 were the Linux package and 13,555 the Intel Mac package. No Apple Silicon package existed before version 0.5.0. conda-forge counts every download, including mirrors and automated systems, so the number of people is smaller than the number of downloads.

PyPI downloads

Weekly downloads from PyPI with mirrors excluded, which is closer to real installs. mbirtorch was first released in August 2026. In the last six months: svmbir 3,985, mbirjax 2,561, mbirtorch 546.

Sources

conda-forge counts: the anaconda.org API, all files of the svmbir package, totals since the first conda-forge release in 2022. PyPI counts: pypistats.org, daily downloads with mirrors excluded, the most recent six months. GitHub: the repositories' star dates and counts.
